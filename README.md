# Groom Wedding Invitation — Marriage Only

Standalone deployable project for the groom invitation. The engagement section is fully hidden; the invitation begins with the marriage ceremony. It is served from the deployment root (`/`).

## Commands

- `npm run build` — produces the static deployment files in `dist/`.
- `npm run dev` — builds the project and starts the local static server.

For a static-host deployment, use `dist` as the publish/output directory.
